# Меню команд по "/" (setMyCommands)

**Date:** 2026-06-05 14:18
**Files:** src/modules/bot/bot-commands.service.ts, bot.module.ts
**Severity:** low

## Problem

При вводе "/" в Telegram бот не показывал список доступных команд — приходилось
помнить их или открывать /help.

## Root Cause

Меню команд в Telegram задаётся через Bot API `setMyCommands`. Вызов нигде не
выполнялся, поэтому клиент Telegram не знал список команд бота.

## Solution

Добавлен `BotCommandsService` (OnModuleInit), который через `@InjectBot`
вызывает `bot.telegram.setMyCommands([...])` со списком всех команд и описаний.
Вызов обёрнут в try/catch — сетевой сбой не роняет старт. Зарегистрирован в
BotModule.

## Prevention

- Команды и меню держать в одном месте; при добавлении новой команды обновлять
  список в BotCommandsService.
- Сетевые вызовы в onModuleInit оборачивать try/catch, чтобы не падал bootstrap.
